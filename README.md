# bandcopy

コピーしたい曲の音源から、**パート別の練習音源**と**演奏しやすい難易度に落とした楽譜**を自動生成するツールです。

近年の楽曲は音が重なりすぎ・技巧的すぎてバンドコピーが難しいことが多くあります。市販ツール（Moises、Klangio など）は分離と採譜まではできますが、**「難易度を下げる」機能がありません**。そこがこのツールの独自部分です。とくにドラムは、ダブルキックなど高難度の技術を「叩ける形」に簡略化することを主眼にしています。

> 精度は7〜8割が上限です。**「AIが8割やり、人が2割を耳と手で直す」**前提で設計しています。完璧な採譜ツールではありません。

## できること

- 音源を4パート（ドラム / ベース / ギター・キーボード等 / ボーカル）に分離（Demucs）
- 各パートを採譜（Basic Pitch、ドラムを除く）
- 難易度レベル1〜5に簡略化（グリッド吸着・短音削除・和音削減・連打統合）
- 全パートを1枚に統合したバンド譜（MusicXML / PDF）
- ギター・ベースのタブ譜出力
- 伴奏パートへのコードネーム自動付与
- ドラム譜のグリッド編集エディタ（ブラウザ）＋「キック間引き」「ハイハットを軽く」などの簡略化コマンド
- 非エンジニア向けの Web UI（ローカル / Google Colab）

## パイプライン

```
音源(MP3)
  ↓ librosa            テンポ検出
  ↓ Demucs (htdemucs)  4パート分離（drums/bass/other/vocals）
  ↓ Basic Pitch        採譜（MIDI化）※ドラムは音程がないため除外
  ↓ simplify.py        難易度レベル1〜5に簡略化
  ↓ music21            MusicXML出力
楽譜 + パート別音源
```

## 動作環境

- **Python 3.10〜3.12**（Basic Pitch が 3.13 未対応）
- **ffmpeg**（MP3変換に必要）
- Demucs は初回実行時にモデル（数百MB）を自動ダウンロードします
- CPUのみだと1曲あたり5〜15分。GPUがあれば1分程度

## セットアップ

```bash
git clone <このリポジトリのURL>
cd bandcopy
python3.12 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt   # 完全再現は requirements.lock.txt
```

ffmpeg の導入（未導入の場合）:

```bash
# Mac
brew install ffmpeg
# Windows
winget install ffmpeg
```

## 使い方

### CLI一括（分離→採譜→簡略化→楽譜）

```bash
./venv/bin/python bandcopy.py <音源> --level 3        # --six で6分離（ギター/鍵盤を別段化）
```

### 全パート統合スコア（バンド譜）

```bash
./venv/bin/python score_all.py <出力フォルダ> --audio <音源> --pdf
```

### タブ譜（ギター・ベース）

```bash
./venv/bin/python tab.py <出力フォルダ> --level 3 --pdf
```

### ドラム譜エディタ（ブラウザ）

```bash
PORT=5050 ./venv/bin/python run_editor.py <音源>   # → http://127.0.0.1:5050
```

グリッドの升目をクリックして打点をON/OFF、「キック間引き」「ハイハットを軽く」で難所を軽くし、「スコア用に保存」で統合スコアに反映できます。

### Web UI（非エンジニア向け）

```bash
./venv/bin/python webapp.py    # → http://127.0.0.1:7860
```

Google Colab の無料GPUで動かす場合は `bandcopy_colab.ipynb` を開いてください（各自が自分の音源をアップロードして処理する方式）。

非エンジニア向けの詳しい操作手順は [手順書.md](手順書.md) にあります。
